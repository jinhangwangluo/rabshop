# 乖乖兔多商户商城系统

乖乖兔是一套以多商户商城为主、知识付费为辅的电商平台系统，覆盖商品交易、商户入驻、直播运营、内容付费和移动端交易场景。项目包含总平台管理端、商户管理端、UniApp/H5 用户端和 ThinkPHP 后端接口，内置平台商品 + 商户商品双主体经营、商品规格与 SKU、运费模板、购物车、商城订单、优惠券、付费 VIP、积分签到、财务、会员、分销、专题课程、直播、消息触达、AI 生产力、客服知识库、DIY 装修、微信生态与支付等能力；知识付费内容（图文、音频、视频、专题/课程合集）与商品共用同一套交易、会员与营销体系。

## 系统定位

- **三端一体**：总平台管理端、商户管理端、用户移动端共用同一后端业务体系。
- **多商户经营**：支持商户入驻、审核、店铺设置、经营统计、提现、内容运营、订单处理和直播经营。
- **双主体供给**：当前内容支持平台发布和商户发布共同运营，后续商品也延续平台商品 + 商户商品共营逻辑。
- **内容付费闭环**：支持图文、音频、视频、小说、专题/课程合集、试看/试听、收藏、评论、搜索和用户购买记录。
- **直播互动交易**：支持主播、直播间、推拉流、评论互动、礼物打赏、直播商品挂载、回放和贡献榜。
- **交易与资产体系**：支持购物车、订单、支付、退款、评价、余额、积分、金币、经验、佣金、充值、提现、会员和分销。
- **消息触达能力**：支持后台消息中心、WebSocket 未读提醒、短信、公众号模板消息、小程序订阅消息、企微/钉钉/自定义 Webhook 和推送日志。
- **会员营销能力**：支持付费 VIP、会员套餐、会员开通/续期、会员协议、会员权益、会员折扣、会员积分倍数和积分页会员广告。
- **优惠券与积分签到**：支持平台券、店铺券、商品券、品类券、主动领取、后台发放、满赠/新人/买赠/首单赠送、积分抵扣、7 天签到奖励和每日任务。
- **AI 生产力与客服能力**：内置内容润色写作、文件库 AI 生图、`AI帮我配置`、客服会话、话术、知识库、知识分段、QA、向量化、AI 模型配置和测试回复。
- **运营装修能力**：内置 DIY 页面装修、个人中心装修、链接管理、移动端组件数据聚合、优惠券和每日签到。

## 内置基础能力

- **统一路由**：`route/admin.php`、`route/merchant.php`、`route/mobile.php` 显式定义三端接口。
- **权限与中间件**：管理员、商户、移动端登录态与权限校验独立处理。
- **双主体运营**：内容通过平台内容和商户内容共同供给，商品底座保留平台商品和商户商品的归属口径。
- **文件服务**：支持分类文件库、普通上传、分片上传、云存储直传登记和 AI 生图任务。
- **AI 生产力**：内容编辑支持 AI 辅助写作与润色，配置模板支持 `AI帮我配置`，文件库支持 AI 生图，客服知识库支持向量化问答。
- **消息触达**：后台消息中心、短信、公众号模板消息、小程序订阅消息、企微/钉钉/自定义 Webhook、模板变量、日志和测试发送。
- **会员营销**：VIP 会员套餐、开通续期、会员折扣、会员积分倍数、会员权益、会员协议和积分页广告。
- **积分签到**：积分账户、积分流水、积分抵扣、订单赠送积分、7 天签到奖励、签到任务和防重复领取。
- **实时通信**：WebSocket 支撑直播聊天、客服会话和后台消息推送。
- **支付链路**：订单支付、用户充值、微信/支付宝回调、退款回调和支付方式配置。
- **队列与异步**：Think Queue 可支撑知识库向量化、批量任务和异步处理。
- **微信生态**：公众号 OAuth、JSSDK、小程序登录、公众号菜单和关键字回复。
- **安全运营**：敏感词管理、操作日志、登录验证码、请求锁、权限路由和跨域中间件。
