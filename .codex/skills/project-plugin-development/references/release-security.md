# 发布与安全边界

- 初始化、校验和打包只允许在指定仓库根目录内读写；输出路径也必须位于仓库内，父目录中的软链接会被拒绝。
- 初始化遇到任一已有插件目录、前端目录、危险软链接或不合法参数即停止；不会覆盖或合并用户源码。
- 插件包不得携带私钥、访问令牌、`.env`、运行状态或构建缓存。敏感配置在运行时由安全配置服务管理，清单只能声明键名和是否敏感。
- 覆盖目标必须是清单中的白名单路径，并记录基础 SHA-256；禁止覆盖核心入口、根路由、`app/event.php`、宿主 `pages.json`、`.git` 或任意绝对路径。
- 校验 ZIP 时先拒绝绝对路径、`..` 和危险软链接，再解包到隔离临时目录；不信任 ZIP 内的权限和时间戳。
- 本地源码包不是可安装制品。安装、升级、卸载、回滚、数据库迁移、远程上传和正式签名必须经过独立任务、权限和审计流程。
