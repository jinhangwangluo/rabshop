## 2. 顶部轮播

- 位置：站点导航下方，全宽浅蓝渐变，内容宽 1200px。
- 3 张幻灯片，淡入切换；下方只有一条 48px 的进度条（没有圆点、箭头或多段指示器），默认居中；右侧是暂停/播放按钮；键盘 ←/→；点击进度条切到下一张。
- 自动播放 7 秒；蓝色填充条从左向右覆盖整条进度条，覆盖完成后切换到下一张；切换后进度条重置。
- 鼠标悬停、键盘聚焦、切到后台时暂停，进度条动画同步冻结；离开后恢复。
- 开启「减少动态效果」时关闭自动播放和淡入，进度条直接显示为蓝色满格。
- 轮播下方增加白色亮点条（Tigshop 式）：多商户商城 / 知识付费两个产品亮点，带 3D 图标。
- 非当前幻灯片设置 `inert` + `aria-hidden`，避免键盘 Tab 进入隐藏内容。
- 第 1 张：主标题 + 三条能力点 + 双 CTA + 三台真机截图 + 3D 图标。
- 第 2 张：三张价格卡：PHP 免费版（免费使用、部分功能加密）/ Java 版（¥1388）/ 企业版（¥5999、无加密完整源码）+ 双 CTA。
- 第 3 张：内容付费 / 直播 / 营销 / 分销 / 装修 / AI 客服 的 3D 图标拼贴 + 双 CTA。

## 7. 响应式

| 断点 | 变化 |
| --- | --- |
| > 1080px | 轮播左右分栏；产品段落左右分栏 + 粘性视觉 |
| ≤ 1080px | 轮播单列，文案居中，视觉在下方；产品段落保持双栏到 1024 |
| ≤ 1024px | 产品段落单列，视觉在上；对比分类 2×2 |
| ≤ 760px | 轮播单列、只保留主手机；对比表堆叠；卡片/段落单列 |
| ≤ 360px | CTA 整行堆叠；轮播进度条缩短 |

已实测 320 / 390 / 768 / 1024 无横向溢出。

**已知全站问题**：现有头部在 768px 会把「关于我们」挤到登录按钮下方；本次设计稿未改全局头部，建议单独把折叠断点提到 920–1024。
